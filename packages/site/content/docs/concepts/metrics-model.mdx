The monitors record OpenTelemetry histograms, counters and gauges through a `Meter` that the caller gives. All durations are in milliseconds. A gauge with a name that ends in `_max_gauge`, `_avg_gauge` or `_rate_gauge` covers the period since the previous collection. Attributes have only a small, fixed set of values, because each set of attributes is a separate time series.
