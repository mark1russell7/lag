`@lag/core` is a set of monitors for browser apps. Each monitor measures one signal of main-thread responsiveness and records it as an OpenTelemetry metric. `setupAllMonitors()` connects all the monitors that the browser supports to one `Meter`. The `@lag/worker` package adds a Web Worker that measures main-thread blocking from outside the main thread.
