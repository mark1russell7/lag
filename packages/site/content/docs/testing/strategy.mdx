The unit tests of `@lag/core` use fake timers, so they are fast and give the same result each time. The integration tests run the monitors in a real Chromium, with Vitest browser mode and Playwright. The stress tests use the workload profiles of `@lag/load` to make main-thread load.

<Tabs label="Test commands">
  <Tab label="Unit tests">
    Run `pnpm --filter @lag/core test`.
  </Tab>
  <Tab label="Browser tests">
    Run `npx vitest run` in `packages/lag-integration-tests`. Without Docker, the OTLP export fails quietly. The assertions do not depend on the export.
  </Tab>
  <Tab label="Site tests">
    Run `pnpm --filter @lag/site test`.
  </Tab>
</Tabs>
