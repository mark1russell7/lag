A Web Worker sends heartbeats with timestamps from its own timer. `WorkerLagMonitor` measures the time until the main thread handles each heartbeat. This time is main-thread blocking, measured while the block occurs and not after it. `createLagWorker()` from `@lag/worker` starts the worker, and the caller terminates it.
